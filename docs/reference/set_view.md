# Set Map Camera View (Center, Zoom, Pitch, Bearing)

Set Map Camera View (Center, Zoom, Pitch, Bearing)

## Usage

``` r
set_view(map, lng, lat, zoom = 10, pitch = 0, bearing = 0)
```

## Arguments

- map:

  A `glmap` widget or `glmap_proxy`.

- lng:

  Longitude of center.

- lat:

  Latitude of center.

- zoom:

  Zoom level (`0` to `22`).

- pitch:

  Pitch tilt in degrees (`0` to `85`).

- bearing:

  Rotation bearing in degrees.
