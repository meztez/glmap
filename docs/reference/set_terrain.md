# Enable 3D Terrain Elevation on the Map

Enable 3D Terrain Elevation on the Map

## Usage

``` r
set_terrain(map, exaggeration = 1.5, source_url = NULL)
```

## Arguments

- map:

  A `glmap` widget or `glmap_proxy`.

- exaggeration:

  Vertical exaggeration factor (default `1.5`).

- source_url:

  Optional Terrarium/Mapbox DEM tile URL.
