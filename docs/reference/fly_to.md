# Smoothly Animate Camera to Target Location (`flyTo`)

Smoothly Animate Camera to Target Location (`flyTo`)

## Usage

``` r
fly_to(map, lng, lat, zoom = 12, pitch = 45, bearing = 0, duration = 1600)
```

## Arguments

- map:

  A `gexplore` widget or `gexplore_proxy`.

- lng:

  Longitude of center.

- lat:

  Latitude of center.

- zoom:

  Zoom level (`0` to `22`).

- pitch:

  Pitch tilt in degrees (`0` to `85`).

- bearing:

  Rotation bearing in degrees.

- duration:

  Animation duration in milliseconds (default `1600`).
