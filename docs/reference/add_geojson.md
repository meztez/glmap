# Add a Raw GeoJSON URL or Object Layer

Add a Raw GeoJSON URL or Object Layer

## Usage

``` r
add_geojson(
  map,
  geojson,
  color = "#22c55e",
  opacity = 0.75,
  id = NULL,
  group = NULL
)
```

## Arguments

- map:

  A `gexplore` widget or `gexplore_proxy`.

- geojson:

  A GeoJSON string, list, or URL.

- color:

  Feature color.

- opacity:

  Feature opacity.

- id:

  Layer ID.

- group:

  Layer group.
