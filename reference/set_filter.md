# Filter Visible Features by Index on the GPU

Filter Visible Features by Index on the GPU

## Usage

``` r
set_filter(map, id, indices = NULL)
```

## Arguments

- map:

  A `glmap` widget or `glmap_proxy`.

- id:

  Layer ID.

- indices:

  Integer vector of 1-based feature indices to keep visible (or `NULL`
  to reset).
