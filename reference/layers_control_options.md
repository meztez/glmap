# Options for `add_layers_control()` (`layers_control_options`)

Drop-in equivalent of `leaflet::layersControlOptions()`.

## Usage

``` r
layers_control_options(collapsed = TRUE, autoZIndex = TRUE)
```

## Arguments

- collapsed:

  Logical; if `TRUE` (default), the control is collapsed into an icon
  button and expands on hover/click.

- autoZIndex:

  Logical; kept for compatibility with `leaflet`.
